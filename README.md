## 🌟 アプリ概要
**HAPBOX** は、スマートフォンのバイブレーション（リニアハプティクスモーター）を自在にカスタマイズし、触感そのものを音楽やゲームのように楽しむための触覚プレイグラウンドアプリです。

スピーカーから音を鳴らすのではなく、**端末の振動周波数と強度（Amplitude）そのものを物理的に響かせる「純粋な触覚バイブレーション駆動」** により、手の中で直接リズム、質感、そして滑らかな強弱のうねりを体感できます。

Nintendo Switch や ニンテンドーDS のゲーム画面を彷彿とさせる、ポップでぷっくりとした親しみやすいデザインを採用。ボタンの数を最小限まで絞り込み、**直感的・感覚的に「触れば判るUX」** に洗練されています。

## 🎮 厳選された5つの触覚体験

### 1. 🎛️ 触覚スタジオ (HAPTIC STUDIO) - 詳細カスタム・プレイグラウンド
**「バイブの強さ・長さ・パターンを自分で自在に操る、究極の触覚シンセサイザー」**
- **リアルタイム波形ビジュアライザー**:
  - CRTオシロスコープ風のネオングリーン波形キャンバス。設定した強弱のエンベロープ（包絡線）が視覚的にリアルタイム描画されます。
  - 再生中（TEST VIBRATION）は光るスキャンライン（プレイヘッド）が波形上を駆け抜け、視覚と指先が完全にシンクロ。
- **7種類の直感パターンシェイプ**:
  - 〰️ **SWELL**: サイン波による滑らかな満ち引き・うねり。
  - 📈 **RAMP UP**: 徐々に加速して最高潮に達するエネルギー上昇。
  - 📉 **RAMP DOWN**: 強いインパクトから余韻を残してフェードアウトする減衰。
  - ⚡ **SOLID**: 一定の力強さで突き抜ける持続ビーム。
  - 💓 **DOUBLE**: トクトクと2連打を刻む鼓動・ダブルビート。
  - 📳 **STUTTER**: 均等に刻まれるリズミカルなスタッカート振動。
  - 🌀 **BOUNCE**: ピンポン玉が弾むように減衰しながら跳ねるバウンド。
- **詳細な強さ・長さ・リピート調整**:
  - **⚡ STRENGTH（強さ）**: 10〜255（4%〜100%）まで1刻みで詳細調整可能。スライダーをドラッグしている最中も指先にリアルタイムで触覚プレビューが伝わります。
  - **⏱️ LENGTH（長さ）**: 30ms（極小）〜3000ms（超ロング連続）まで自在に伸縮。
  - **🔁 REPEAT（ループ設定）**: 1-SHOT（単発テスト）とLOOP（連続ループ）の切替。LOOP時はステップ間のインターバル（GAP: 50ms〜1000ms）も詳細設定可能。
- **メモリスロット (A / B / C)**:
  - 気に入った波形設定を即座に呼び出し可能。長押しで現在のカスタム波形をスロットに保存。
- **巨大なSwitch風アクションボタン**:
  - 画面下部の大きな「TEST VIBRATION / STOP」ボタンで、いつでもワンタップで体感・停止できます。

### 2. 🌊 うねり・連続振動 (HAPTIC SURGE)
- **指先で波を操る触覚ウェーブキャンバス**:
  - キャンバスをなぞると、指の上下移動（Y軸）に応じて**振動の強さが0%から100%まで無段階・完全シームレスに変化（連続スウェル）**。
  - アナログボリュームのように滑らかに強弱がうねり、指先に流体のようなフィードバックが宿ります。
- **4つの大型感覚オーブ**:
  - 🌊 **SWELL**: 0%から100%まで満ち引きする約1.5秒の滑らかな大波のうねり。
  - 🏎️ **THROTTLE**: 押し続けている間、アイドリングからレッドゾーンまで一気に加速する連続エンジン振動。
  - ⚡ **CHARGE**: 指先にエネルギーが溜まり、限界でパチンと弾ける連続チャージ。
  - 🐱 **PURR**: 猫が喉を鳴らすような、穏やかでリズミカルな持続的呼吸波形。

### 3. 🧪 触感ラボ (TOUCH LAB)
ボタンによる複雑な設定を排し、3つの代表的マテリアルを切り替えて楽しむ触覚トイ。
- 🫧 **BUBBLE (無限プチプチ)**:
  - 画面いっぱいの大きな気泡シート。タップはもちろん、**指でなぞるだけで次々と連続割り**できる快感設計。全て割ると自動でパルスとともにリセット。
- 🧲 **MAGNET (磁性流体 / 連続抵抗)**:
  - 磁極の間を指で泳がせると、指の速度と磁石の距離に応じた**滑らかな連続抵抗振動**が粘性のように指先にまとわりつきます。
- ⚙️ **GEAR (精密歯車の回転)**:
  - 画面中央の大きな歯車を指で直接回すと、歯がカチッカチッと噛み合う確かな手応えと慣性を楽しめます。

### 4. 🪐 ゴーストコア (GHOST CORE) - 完全ボタンレスの触覚生命体
**「画面に触れると、手の中で生きている」**
- ボタンやスライダーを一切配置せず、画面全体を重力と生命のフィールドとして構築。
- **傾けて感じる重力**: スマホを傾けると、見えない重たい液銀の塊が手の中で滑り落ち、壁にぶつかった瞬間だけ「ドスン」と確かな重み（`thud`）が伝わります。机の上に置いても余計な振動は一切起きない静止安定設計。
- **触れて感じる心拍**: 画面上のコアに指を触れている間だけ、手の中でドク…ドク…と温かい心拍が脈打ちます。指を離せば即座に静止。
- **引っ張って弾く張力**: コアを指でゴムのように引っ張ると、**引っ張る距離に応じて振動が滑らかに高まり（張力ハプティクス）**、指を離した瞬間にスリングショットのように弾ける反動が手元に響きます。

### 5. 🥁 ビート・マトリクス (BEATS)
- 複雑なメニューや多数のボタンを廃止し、8つの大きなビートパッドに集約。
- **触れば判る直感操作**:
  - パッドをタップしてON/OFF。
  - **パッドを上下にスワイプするだけで、各ステップの振動強度をリアルタイムに滑らかに調整**。
  - パッドを長押しすると、通常のクリックから**「⚡ BEAM（長時間連続照射）」**へ切り替え可能。
- 巨大なSwitch風PLAY/STOPボタンと、直感的なテンポスライダーで自分だけのリズムを刻めます。

## 🛠️ 技術スタック & アーキテクチャ
- **Framework**: Flutter 3.x (Impeller Vulkan)
- **Application ID / Bundle ID**: `com.oyaiz.apps.hapbox`
- **Domain**: `hapbox.apps.oyaiz.com`
- **Native Android Haptics (`MainActivity.kt`)**:
  - **OS設定フィルタの完全回避**: `VibrationAttributes.USAGE_MEDIA` および `AudioAttributes.USAGE_GAME` を指定し、Androidの「タッチ操作バイブOFF」設定に干渉されずに100%確実に振動を再生。
  - **連続波形合成 (`createWaveform`)**: 16〜18ms間隔のマイクロステップ配列により、完全シームレスな連続強度変化（スウェル、イーズイン、イーズアウト）を端末ネイティブ側で合成。
  - **リアルタイム持続制御 (`setContinuous`)**: 指のドラッグ移動に合わせて、毎フレーム途切れなく強度を更新し、指を離せば瞬時に完全停止。
- **Motion Sensor**:
  - Android `SensorManager` (TYPE_GRAVITY / TYPE_ACCELEROMETER) via `EventChannel`
- **Audio Output**: 0% (完全無音・スピーカー音声不使用)
